## <a name="introduction">🤖 Introduction</a>

A visually rich, Awwwards-style website featuring scroll-triggered animations, clip-path geometric transitions, 3D hover effects, and video storytelling — built for a luxurious, modern feel with smooth, responsive UI/UX.

Deployed at: **https://awwwardswebsite.netlify.app/**

## <a name="tech-stack">⚙️ Tech Stack</a>

- React.js
- GSAP
- Tailwind CSS
- Vite

## <a name="features">🔋 Features</a>

- **Scroll-Based Animations** — Dynamic animations triggered by scroll position for an engaging feel.
- **Clip-Path Shaped Animations** — Geometric transitions using CSS clip-paths.
- **3D Hover Effects** — Interactive 3D transforms that respond to user input.
- **Video Transitions** — Integrated video elements woven into the storytelling.
- **Smooth UI/UX** — Polished, buttery-smooth interactions throughout.
- **Fully Responsive** — Consistent experience across all screen sizes.

## <a name="quick-start">🤸 Quick Start</a>

**Prerequisites**

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/en)
- npm

**Clone & Install**

```bash
git clone https://github.com/XLr8ben/awwwards-website.git
cd awwwards-website
npm install
```

**Run Locally**

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

**Build for Production**

```bash
npm run build
```
